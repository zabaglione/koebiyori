# 初めて使う方へ

このページでは、M5Burnerでkoebiyoriを直接書き込む方法と、共通のAPI・Wi-Fi設定を説明します。ほかのアプリも切り替えて使う方は、先に[ランチャーで使う](launcher.md)を参照してください。通常の利用にPython、ソースコードの編集、自前の中継サーバーは不要です。

配布ファイルと対応するソースは [GitHub Releases](https://github.com/zabaglione/koebiyori/releases) からも取得できます。自分でファームウェアを作る場合は[ビルドガイド](build.md)を参照してください。

## 用意するもの

- M5Stack CoreS3、データ通信できるUSB-Cケーブル、Windows・macOS・LinuxのPC
- [M5Burner](https://docs.m5stack.com/ja/uiflow/m5burner/intro)とM5Stackコミュニティアカウント
- 2.4GHz Wi-Fiのネットワーク名（SSID）とパスワード
- 利用者自身のOpenAI APIキー

Core2やCoreS3 SEなど別機種は対象外です。内蔵のマイク・スピーカーを使います。設定が終われば、会話中にPCやM5Burnerを起動しておく必要はありません。

## 1. OpenAI APIを準備する

1. [OpenAI Platform](https://platform.openai.com/)へログインし、利用するプロジェクトを選びます。
2. [Billing](https://platform.openai.com/settings/organization/billing/overview)でAPIの支払い設定を確認します。**ChatGPTの契約とAPIの課金は別です。** [公式の説明](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)
3. [API keys](https://platform.openai.com/api-keys)でキーを作成し、安全に保管します。キーは他の利用者と共有しないでください。
4. 音声用の `gpt-live-1` と検索・推論用の `gpt-5.6-luna` を利用できることを確認します。利用可否はプロジェクトの権限や契約状況によります。

APIキーはOpenAIへの接続に使います。リポジトリの作者へ送る仕組みはありません。会話の音声・文脈はOpenAIへ送信され、検索時は質問に必要な内容が検索処理にも使われます。声はAIが生成します。

## 2. M5Burnerで書き込む

1. [公式ページ](https://docs.m5stack.com/ja/uiflow/m5burner/intro)から、お使いのOS向けのM5Burnerを入れます。
2. M5Burnerを起動し、M5Stackコミュニティアカウントでログインします。OpenAIとは別のアカウントです。
3. CoreS3をUSBで接続します。
4. 機種を **CORES3** にし、`koebiyori` を検索します。**Only Official** はオフにしてください。
5. **Download** でファームウェアを取得し、**Burn** を押します。
6. CoreS3のCOMポートを選び、書き込みを開始します。完了するまでUSBを抜かないでください。
7. 書き込み画面を閉じ、CoreS3にサラが表示されるまで待ちます。

**直接書き込むと、既存のLauncher・アプリとWi-Fi・APIキーの設定は消去されます。** この配布ファームウェアは設定領域を空にしてあるため、直接書き込みでの更新時も次の手順で設定し直してください。Launcherを残す場合は[Launcher経由のインストール](launcher.md)を使います。

COMポートはWindowsでは `COM3` など、macOSでは `tty.usbmodem...`、Linuxでは `ttyACM0` などと表示されます。複数ある場合はUSBを抜き差しし、増減するポートを確認してください。

## 3. Wi-FiとAPIキーを保存する

Launcherを利用する場合も、**先にkoebiyoriを起動し、サラが表示された状態**で設定します。Launcher自身のWi-Fi設定とは別に保存されます。

1. M5Burnerの左側で **USER CUSTOM** を選び、**BurnerNVS** を押します。「Burner NVS」という設定画面が開きます。
2. CoreS3のCOMポートを選び、**Connect** を押します。
3. 次の3項目でそれぞれ **Get** を押すと、入力欄が現れます。

| 項目 | 入力するもの |
| --- | --- |
| `wifi_ssid` | 接続する2.4GHz Wi-FiのSSID。32バイト以内 |
| `wifi_password` | Wi-Fiのパスワード。通常8〜63バイト。パスワードなしのネットワークでは空欄 |
| `openai_api_key` | OpenAI Platformで作成した `sk-` から始まるAPIキー |

4. 入力欄を書き換えたら、**その項目の保存アイコンを押すか、入力欄でEnterを押します。3項目それぞれを保存してください。**
5. 最後に `status` の **Get** を押します。既に表示している場合は、その行の更新アイコンで読み直します。
6. `READY - disconnect Burner NVS and restart CoreS3` と表示されたら、Burner NVSを閉じてCoreS3をリセットします。Launcherの画面が出た場合はkoebiyoriを選びます。
7. Wi-Fiと時刻の同期が終わり、左上が待機アイコンになれば使えます。

`status` は読み取り専用です。`READY` は入力内容が保存されたという意味で、Wi-Fi接続やAPIの利用権限は再起動後に確認されます。`ERROR` が出た場合は該当の項目を修正・保存し、`status` を読み直してください。M5Burner側の保存通知だけで判断しないでください。

**パスワードとAPIキーは、再取得すると `********` と表示されます。** この伏せ字を保存しても既存の値は維持されます。変更したい場合は新しい値に置き換えて保存します。貼り付けた直後の入力内容はM5Burnerの画面に見えるため、画面共有やスクリーンショットに含めないでください。

設定は本体のNVS（電源を切っても残る保存領域）に保存されます。設定中は手かざしで会話を始めません。設定画面を閉じただけでは利用モードに戻らないので、必ず本体をリセットしてください。**Add・購読ボタン・Reset NVSは通常の設定には使いません。**

## 4. 話してみる

1. 起動直後は画面下のセンサーの前を空け、待機表示から約1.5秒待ちます。
2. 手を近づけて約0.2秒かざします。「来てくれたんだ。ちょっと待ってね」と聞こえたら手を離して構いません。
3. 左上がマイクのアイコンになったら、自然な声で話します。返答中も声で割り込めます。
4. 「今日の東京の天気は？」など最新情報を尋ねると検索します。地域が不明な質問には聞き返します。
5. 画面をタップするとミュート・終了ボタンが現れます。操作しなければ5秒で隠れます。待機中の緑の受話器から手動で開始することもできます。

会話が30秒ないと「またね」と声をかけて待機へ戻ります。検索の応答待ちは一定時間この判定を保留し、長引けば遅れていることを伝えます。1回の会話は最大5分です。

画面には会話文や検索結果の文章を表示しません。左上の状態アイコンと右上のWi-Fi表示で動作を確認できます。検索の回答は声で短く要約するため、日付・場所・条件を具体的に伝えてください。

## 料金

料金は **音声セッションの時間 + 委譲先モデルの処理 + Web検索ツール** の合計です。音声セッション中は無言・ミュート・検索待ちの時間も含まれます。終了ボタンや自動終了でセッションを閉じるまで、ミュートだけでは終了になりません。開始時の保存済み音声を再生するためのTTS呼び出しはありません。[OpenAI公式の費用説明](https://developers.openai.com/api/docs/guides/voice-latency-cost?api=live)

単価は変更されるため、利用前に[API料金表](https://developers.openai.com/api/docs/pricing)と[Usage](https://platform.openai.com/usage)を確認してください。アプリの5分制限は1回の会話の制限で、アカウント全体の予算上限を設定する機能ではありません。

## 設定の変更と消去

Wi-FiやAPIキーを変えるときは会話を終了し、上記のBurner NVS画面で該当項目を保存して本体をリセットします。通常の電源の入れ直しでは設定は消えません。

本体を譲る場合は、**M5BurnerのEraseでフラッシュ全体を消去**してください。保存欄を空にするだけでは、保存領域に過去の値が残る可能性があります。全消去するとアプリも消えるため、次の利用者がファームウェアを書き込み、自分の設定を入力します。

本体の保存領域は暗号化していません。APIキーが漏れた場合は、OpenAI Platformでそのキーを無効化し、新しいキーを設定してください。設定済みの本体から書き出したフラッシュデータを配布しないでください。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| `koebiyori` が見つからない | 掲載状況、CORES3の選択、Only Officialがオフか |
| USBポートが見つからない | データ通信できるケーブルか、USB接続先、公式CoreS3のUSB案内 |
| Burner NVSへ接続できない | 書き込み完了後にアプリが起動したか。他のUSBモニターを閉じ、CoreS3をリセットして接続し直す |
| `__NVS_NOT_FOUND__` が出る | koebiyoriが起動しているか。書き込んだ機種・ファームウェアを確認 |
| `status` が `SETUP` のまま | SSIDとAPIキーを両方保存したか。貼り付けただけでは保存されない |
| `ERROR - invalid ...` | SSIDの長さ、パスワードの長さ、APIキーに余分な空白や改行がないか |
| `BUSY` が出る | 会話を終えてから設定する。必要なら本体をリセットして再接続 |
| 設定後も手かざしで始まらない | Burner NVSを閉じ、本体をリセットしたか |
| Wi-Fiに接続できない | 2.4GHzのSSID、パスワード、電波状態 |
| 時計アイコンから進まない | インターネット接続、NTP通信が遮断されていないか |
| 会話開始時にエラーになる | APIキー、支払い設定、モデルへのアクセス権、Usage上の制限 |
| 手かざしへの反応が弱い | センサー前を空けて待機し直す。画面の緑の受話器でも開始可能 |
| 検索が遅い・情報が見つからない | 日付と地域を具体的に伝える。通信状態によって時間が変わる |
