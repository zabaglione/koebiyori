# koebiyori（こえびより）

手をかざすと、声と表情で応える。M5Stack CoreS3で動く、小さなキャラクターです。

内蔵のマイク・スピーカー・画面だけで、声による割り込みができる会話とWeb検索を楽しめます。CoreS3からOpenAIへ直接接続するので、会話中にPCや自前の中継サーバーを動かしておく必要はありません。

![サンプルキャラクター「サラ」の表示用イラスト](assets/generated/portrait.png)

サンプルキャラクターは「サラ」。上の画像は表示用の素材です。実際の画面では口と目が動き、左上に状態アイコン、右上にWi-Fi表示が付きます。

**利用者自身のOpenAI APIキーと2.4GHz Wi-Fiが必要です。APIの利用料金が発生します。ChatGPTの契約とは別です。** [APIキーと料金の説明](docs/setup.md)

## できること

- 手をかざすと、保存済みの短い声ですぐに反応し、その間に会話へ接続
- 返答中も話しかけられる音声会話。録音ボタンの長押しは不要
- 天気、ニュース、イベント、映画など、最新情報が必要な質問をWeb検索
- 声に合わせた口の動き、まばたき、待機中の小さな揺れ
- 30秒間会話がなければ「またね」と挨拶して待機へ復帰
- 性格・声・検索・地域を設定ファイルで変更

会話の音声は `gpt-live-1`、検索・推論は `gpt-5.6-luna` を使用します。モデルへのアクセス権とAPIの支払い設定を確認してください。検索内容は声で短く返します。

## 始める

M5Stack CoreS3、データ通信できるUSB-Cケーブル、書き込み用PC、2.4GHz Wi-Fi、OpenAI APIキーを用意します。

M5Burnerでファームウェアを書き込み、Wi-FiとAPIキーを設定します。通常の利用にPythonやソースコードの編集は不要です。配布ファイルと対応するソースは [GitHub Releases](https://github.com/zabaglione/koebiyori/releases) にまとめています。

1. [導入ガイド](docs/setup.md)に沿って、M5Burnerで `koebiyori` を書き込みます。
2. M5Burnerの **BurnerNVS** でWi-FiとAPIキーを保存し、本体をリセットします。
3. 起動後、画面下のセンサーの前を空けて約1.5秒待ちます。
4. 手を約0.2秒かざし、短い開始音声が聞こえたら手を離します。
5. 接続後、左上がマイクのアイコンになったら話しかけます。

画面をタップすると、ミュート・終了ボタンが現れます。操作しなければ5秒で隠れます。待機中のタップから手動で会話を始めることもできます。

## 利用について

対象機種はM5Stack CoreS3です。Core2やCoreS3 SEなど、別機種向けの構成は用意していません。

聞き取りやすいよう、本体に向かって自然な声で話してください。周囲の騒音・反響・通信状態によって、聞き取りや返答までの時間が変わります。

1回の会話は最大5分です。音声・会話の文脈はOpenAIへ送信されます。本体に保存するAPIキーとWi-Fi設定は、この実装では暗号化していません。本体を譲る前の設定消去などは[導入ガイド](docs/setup.md)を参照してください。
